1治理结论（管理层摘要）

v2 映射存在系统性错绑，本次全量重治理后：全量消耗 14.61亿 → 9.92亿（-32%），闭环消耗 10.89亿 → 9.19亿（-16%）。差异主体是三类错绑：① 第三方酒商蹭品牌词（拉菲/汾酒）；② 多品牌经销/品宣账户被整体错挂（酒小二/顶新德克士）；③ 无店铺无佐证的单维特征行。自营基础扎实的头部品牌（诺特兰德 99.8%、华大营养、叮叮懒人菜 98%）几乎不受影响——重治理削掉的是"不属于品牌的钱"，品牌自投部分分毫未动。被移出的 6,455 条品牌×主体记录（日耗口径约 3.3 亿/8个月）进入待确认池：经品牌方授权确认属经销商投放的，可按科目加回。

2映射规则 v3.1（经项目组对抗审校）

Tier A 店铺锚点 行的小店ID ∈ adhome 品牌店铺集 → 计入；特征字段明确指向他牌的 781 行 → 店铺-特征冲突进待确认（Review 意见：不直接按店铺归，防一店多牌）。
Tier B 多维自证 店铺不在底表：品牌特征含品牌词（必要）＋ 视频号/店铺注释/客户简称/OPS ≥2 维含品牌词（短词品牌 ≤2字需 ≥3 维，Review 意见：防"汾酒味/同款"类误匹配）。
Tier B2 专属账户 特征含品牌词 + 该 OPS 全库仅与此品牌共现 + ≥1 维佐证（Review 意见：按主体×品牌对验证，防独立主体绕过）。
Tier B3 账户自证 无特征无店铺：客户简称/OPS 含品牌词 + 视频号或店铺注释 ≥1 维佐证。
Tier W 白名单 人工确认合法关联主体：顶巧→康师傅、雷米君度→人头马、壹佰米(叮咚买菜)→加点滋味。
待确认池 其余行不计入 TR：经销商/代投/蹭名主体——凭品牌授权名单逐主体加回，财务上与品牌直投分列、可审计。
